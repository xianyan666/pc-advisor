# PC硬件推荐系统 开发报告

## 项目概述

基于 Spring Boot + MyBatis-Plus 的 PC 硬件推荐系统，提供用户注册、登录认证及硬件产品展示功能。

---

## 一、Bug 修复

### 1.1 管理员登录后无法导向主页

**问题**：`login.html` 中 `redirectAfterLogin()` 将 ADMIN 角色定向到 `/admin/dashboard.html`，该页面不存在，导致 404。

**修复**：`redirectAfterLogin()` 统一跳转至 `/index.html`，所有角色登录后均进入主页。

**涉及文件**：
- `src/main/resources/static/login.html`
- `src/main/java/com/pcadvisor/web/public/login.html`

---

### 1.2 普通用户登录后主页仍显示登录按钮

**问题**：`index.html` 中登录链接的 CSS 类为 `hidden md:block`。`updateUIByLoginStatus()` 已登录时只添加 `hidden` 类，但 Tailwind 的 `md:block` 在桌面端优先级更高，登录按钮仍然可见。

**修复**：已登录时同时移除 `md:block`，未登录时加回 `md:block`。

**涉及文件**：
- `src/main/resources/static/index.html`

## 三、注册功能实现

### 3.1 后端

#### 3.1.1 新增 RegisterRequest DTO

`dto/RegisterRequest.java` — 注册请求体，包含字段校验：

| 字段 | 校验规则 |
|------|----------|
| `userName` | `@NotBlank`, 2-20 字符 |
| `password` | `@NotBlank`, 6-50 字符 |
| `userMailbox` | `@Email`（可选） |
| `userPhone` | 无校验（可选） |

#### 3.1.2 改造注册接口

`AuthController.register()` 改为接收 `@RequestBody RegisterRequest`，密码通过请求体传输，不再使用 URL 查询参数。

#### 3.1.3 数据持久化

注册时向两张表写入数据：
- `sys_user` — 登录凭证（用户名、MD5 加密密码、角色 `ORDINARY`）
- `OrdinaryUser` — 用户详情（用户名、手机号、邮箱、注册时间）

---

### 3.2 前端

`register.html` — 完整注册页面，包含：

- 用户名、密码、确认密码、邮箱、手机号五个输入框
- 客户端校验（用户名字符长度、密码长度、两次密码一致性、邮箱格式、手机号格式）
- 密码可见性切换
- 注册成功跳转登录页，失败 SweetAlert2 弹窗提示

## 四、注册异常修复

### 4.1 重复提交导致"用户名已存在"误报

**问题**：用户首次注册成功（数据入库），但因网络延迟或重复点击触发了第二次请求，第二次请求因用户名已存在而报错，用户误以为注册失败。

**修复**：

| 修复项 | 说明 |
|--------|------|
| `@Transactional` | `register()` 添加 `@Transactional(rollbackFor = Exception.class)`，确保 `sys_user` 和 `OrdinaryUser` 两张表插入原子化 |
| BusinessException | `register()` 和 `login()` 中的 `RuntimeException` 替换为 `BusinessException`，业务校验失败以 WARN 级别日志记录，不再输出完整堆栈 |
| 防重复提交 | `register.html` 添加 `isSubmitting` 锁标志，首次提交后禁用按钮，`finally` 块中重置 |

**涉及文件**：
- `src/main/java/com/pcadvisor/service/impl/UserServiceImpl.java`
- `src/main/resources/static/register.html`

---

### 4.2 OrdinaryUser 插入 SQL 列名错误

**问题**：MyBatis-Plus `map-underscore-to-camel-case: true` 将 Java 字段 `userName` 映射为列名 `user_name`，但数据库 `OrdinaryUser` 表实际列名为 `userName`（camelCase），导致 `Unknown column 'user_name'` 错误。

**修复**：给 `OrdinaryUser` 实体的 `userName`、`userPhone`、`userMailbox` 字段添加 `@TableField` 显式指定列名。

**涉及文件**：
- `src/main/java/com/pcadvisor/entity/OrdinaryUser.java`
